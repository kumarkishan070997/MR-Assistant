# Implementation Workflows

This folder contains execution implementation-stage workflow documents.

Use these files after:

- planning has produced approved delivery tasks
- the active work item has entered implementation

Primary contents:

- task-to-code workflow
- implementation input and output contracts
- implementation review rules
- implementation revision rules
- implementation done criteria

These documents govern how approved delivery tasks become frontend or backend code (per the task's `Layer` field) while preserving architecture, progress, and traceability discipline.
